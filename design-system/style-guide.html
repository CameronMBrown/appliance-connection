01 — Foundations

The three rules everything obeys

These constrain every screen. When a choice is unclear, it's resolved by returning to these.

Monochrome base

Black, white, and warm greys carry the brand — the same palette as the trucks. If you removed all colour, it should still read unmistakably as The Appliance Connection.

Colour as punctuation

Deep blue and brass appear sparingly and deliberately — a CTA, a stat, a section accent. Never a blue header bar, never colour for its own sake.

Chrome vs. photography

The interface stays monochrome + accents. Photography is where full colour lives — the gleaming finished kitchen, the install done right. The frame is quiet so the work is loud.

07 — Handoff notes

For the design phase

What's settled, what's open, and where to push.

  • Settled: the token architecture (primitives → semantic roles), the monochrome-base + punctuation rule, the Benguiat/system pairing, and component structure + states.
  • Tweakable defaults: exact hues (the blue's depth, the brass's warmth), the type scale's ceiling, spacing generosity, radii/shadow. Edit primitives; components follow.
  • Needs the real face: license + self-host ITC Benguiat (subset, 1–2 weights) to replace the serif fallback. Headlines will gain their character then.
  • Needs real photography: object/space-led, no stock people. Every card/hero placeholder here is a slot for a finished-install photo.
  • One risk worth taking: lean harder into oversized Benguiat headlines against generous whitespace — the editorial confidence is what separates this from a trades template.
