Centered closing call-to-action — heading, one line, one button. Used to end nearly every page.

```jsx
<CtaBand heading="Have a question?" text="Questions, advice or a quote — we respond within 24 hours." ctaLabel="Contact Us" ctaUrl="/contact" isDark />
```

`isDark` (default true) applies the `.on-dark` scope for a dark closing band; set false for a light-ground mid-page variant.
